# 笔试重点

C++17 / Python 3 的 ACM 笔试备忘。每篇按问题、写法、复杂度和边界条件组织，示例代码与博客正文放在一起。

- `index.md`：系列目录。
- `blog/acm-input-cpp-python/index.md`：输入处理。
- `blog/acm-common-apis/index.md`：常用接口。
- `blog/acm-common-algorithms/index.md`：常见算法。
- `blog/acm-common-tricks/index.md`：常见技巧。

父博客通过 Hugo module mount 将 `blog/` 挂到 `content/post`，文章链接使用 front matter 中的 `slug`。
